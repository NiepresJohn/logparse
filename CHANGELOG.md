## [Unreleased]

### Added
- Initial release of logparse CLI
- Auto-detection for JSON, Docker, Nginx, Syslog, and plain text log formats
- Streaming parser with constant memory usage
- Filter by log level, time range, regex pattern, or field values
- Multiple output formats: table, JSON, CSV
- Shell completion support for Bash, Zsh, Fish, and PowerShell
- Integration with Cobra CLI framework
- Comprehensive test suite with unit and integration tests
- GitHub Actions CI/CD workflow
- GoReleaser configuration for cross-platform releases
